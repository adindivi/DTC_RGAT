dtc_knowledge_graph.json에 신규 커넥터 기입

DTC_RGAT 시스템은 완전한 데이터 기반(Data-Driven) 스키마를 사용하므로, dtc_knowledge_graph.json 파일의 nodes 배열과 edges 배열에 항목을 추가하는 것만으로 즉시 지식 그래프가 확장됩니다.

① nodes 배열에 신규 커넥터 노드 추가

dtc_knowledge_graph.json (nodes) 
{
  "id": "CONN::FLRS_NEW_CONN01",              // 식별자: 반드시 "CONN::" 접두사 준수
  "name": "FLRS_NEW_CONN01 / NEW_FLRS02",       // 화면 표시 명칭 (양방향 커넥터명)
  "node_type": "Connector",                    // 노드 타입 고정값
  "location": "프론트 범퍼 하단 / 휠하우스",     // 장착 물리 위치 메타데이터
  "fault_category": "CONN",                     // 카테고리 (계통 필터용)
  "domain": "CONN",                             // 잠재공간 도메인 색상 키
  "description": "신규 증설된 센서 통합 정션"   // 툴팁 및 상세 제원 설명
}

② edges 배열에 물리 배선(HW_WIRE) 및 마스터 검증선(HW_MAP) 연결

dtc_knowledge_graph.json (edges) 
// 1. 제어기(ECU)와 커넥터 간의 물리 결선 (필수: 최소 1개 이상의 ECU와 연결 필요)
{
  "source": "ECU::ADAS_PRK_MCU",
  "target": "CONN::FLRS_NEW_CONN01",
  "rel": "HW_WIRE",
  "weight": 1.0
},
// 2. DTC 고장 코드와 커넥터 간의 마스터 검증 직결선 (정답 데이터가 있는 경우 선택적 기입)
{
  "source": "DTC::C136887::ADAS_PRK_MCU",
  "target": "CONN::FLRS_NEW_CONN01",
  "rel": "HW_MAP",
  "weight": 1.0
}
⚠️ 고립 노드(Isolated Node) 방지 원칙
어떤 ECU와도 HW_WIRE 배선이 연결되지 않은 고립 커넥터는 시스템의 토폴로지 마스킹(Topology Masking)에 의해 도달 불가능 노이즈로 분류되어 랭킹 계산에서 자동 제외됩니다. 반드시 최소 1개 이상의 담당 ECU와 배선을 연결해 주세요.

RGAT 신경망 재학습 파이프라인 실행

루트 디렉토리의 train_rgat.py를 실행하면, 신규 커넥터가 포함된 전체 지식 그래프의 다중 관계형 어텐션(Relational Graph Attention)을 100 Epoch 동안 학습하여 새로운 64차원 노드 임베딩 벡터를 도출합니다.

Windows PowerShell / 터미널 
# PyTorch 기반 RGAT 신경망 재학습 실행
python train_rgat.py
생성 산출물 파일 형식 / 규격 역할 및 활용처
rgat_model.pt PyTorch Checkpoint 학습된 4-헤드 어텐션 GNN 신경망 가중치
rgat_embeddings.npy NumPy Matrix (N × 64) 전체 노드의 고차원 시맨틱 특징 벡터 (PC 백엔드 실시간 추론용)
rgat_latent_2d.json JSON (2D Coordinates) 64차원을 2차원 t-SNE로 축소한 산점도 좌표 (모바일 바텀시트 캔버스용)
training_curve.png PNG 시각화 차트 학습 및 검증 손실(Loss) / ROC-AUC 수렴 곡선

모바일 온디바이스 엔진 번들 자동 컴파일

스마트폰에서 파이썬이나 넘파이(NumPy) 라이브러리 없이도 0ms 즉각 진단이 가능하도록, build_ondevice_bundle.py가 신규 커넥터 그래프를 순수 자바스크립트 온디바이스 진단 엔진으로 1초 만에 압축 컴파일합니다.

Windows PowerShell / 터미널 
# 신규 커넥터가 반영된 모바일 온디바이스 JS 엔진 빌드
python mobile/scripts/build_ondevice_bundle.py
⚡ On-Device 컴파일러 자동 처리 내역
• 2-Hop 배선망 사전 색인: 신규 커넥터와 직결/간접 연결된 DTC 관계 자동 캐싱
• t-SNE 산점도 병합: 1,705개 이상의 좌표를 경량 JSON으로 번들 내장
• 출력 파일: mobile/static/dtc_ondevice_engine.js (용량 약 930KB)

에셋 동기화 및 오프라인 독립형 APK 빌드

생성된 자바스크립트 엔진과 모바일 UI를 안드로이드 네이티브 에셋 폴더에 동기화한 뒤 원클릭 배치 스크립트로 APK를 빌드합니다.

Windows PowerShell / 터미널 
# 1. 최신 엔진 및 HTML을 안드로이드 네이티브 에셋(assets/)으로 동기화
python mobile/scripts/sync_assets.py

# 2. 안드로이드 스탠드얼론 APK 빌드 실행 (약 3~10초 소요)
cd mobile
.\build_apk.bat
📦 빌드 완료 산출물 위치
디버그 패키지: mobile/app/build/outputs/apk/debug/app-debug.apk (약 5.9 MB)
이 APK 파일을 갤럭시 스마트폰에 설치하면, PC가 꺼져 있거나 Wi-Fi / LTE가 차단된 지하 정비 현장에서도 신규 커넥터 진단이 100% 단독 실행됩니다.
